Guide strategy

Learn the loop before optimizing it.

A useful first goal is understanding what the current interface asks for at each step. Then you can compare upgrades without relying on stale prices or invented shortcuts.

  • Use the live interface for current prices and requirements.
  • Confirm a reset prompt before choosing rebirth.
  • Treat leaderboards as a later goal, not your first lesson.
